# CareerPilot-AI 🚀

CareerPilot-AI is an AI-powered student career preparation platform that helps students prepare for placements through resume analysis, job matching, skill-gap analysis, aptitude practice, mock interviews, coding practice, and resume building.

## ✨ Features

- 📄 AI Resume Analyzer
- 💼 Job Matcher
- 🎯 Skill Gap Analysis
- 🎤 AI Mock Interview
- 🧠 Aptitude Practice
- 💻 AI-Generated Coding Practice
- 📝 ATS Resume Builder
- 👤 Student Profile & Authentication
- 📚 History for interviews, aptitude, jobs and coding practice
